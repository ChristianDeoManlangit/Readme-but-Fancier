## 📘 Overview

This site is a fancier rendition of my GitHub profile. Instead of sticking to the conventional GitHub README format, this version showcases content in a uniquely styled layout built from scratch, offering a more interactive and elegant experience.

---

## ⚙️ Features

- 🌗 Dynamic dark and light mode toggle  
- 🎨 Smooth hover-based animations  
- 🧼 Clean, minimalist, and modern user interface  
- 📱 Fully responsive and mobile-optimized layout
